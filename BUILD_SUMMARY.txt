TROUBLESHOOTING:
───────────────────────────────────────────────────────────────────────────────

Issue: "Cannot connect to Mission Barisal server"
  → Check: curl http://localhost:5000/v1/models
  → Fix: Start server: cd server && node hamba.js

Issue: "Server offline" message
  → Expected if server not running
  → Fix: Start server in Terminal 1

Issue: Messages not streaming
  → Check: Browser console (DevTools → Console)
  → Fix: Restart both servers

Issue: Build errors
  → Run: npm run compile
  → Check: Error messages and fix accordingly
